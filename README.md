# To-Do List Application

A simple, interactive, and responsive **To-Do List Web Application** developed using HTML, CSS, and JavaScript. The application helps users organise their daily activities, manage tasks, and keep track of their progress through an intuitive user interface.

Users can easily add new tasks, edit existing ones, mark tasks as completed, and remove tasks when they are no longer needed.

## Live Demo

**[View To-Do List Application](https://to-do-list-ps593.netlify.app/)**

## Features

- **Add Tasks:** Create new tasks to keep track of daily activities and responsibilities.
- **Edit Tasks:** Modify existing tasks whenever requirements change.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Mark as Completed:** Mark finished tasks to distinguish them from pending activities.
- **Interactive Interface:** Simple and intuitive interface for smooth task management.
- **Responsive Design:** Designed to provide a consistent experience across different screen sizes.
- **Dynamic Updates:** Task-related changes are reflected in the interface through JavaScript DOM manipulation.

## Getting Started

Follow these steps to run the application on your local machine.

### Prerequisites

- A modern web browser (Google Chrome, Firefox, Edge, etc.).
- A code editor such as Visual Studio Code (optional).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/pragati-singh-593/ToDo-List.git
```

**2. Navigate to the project directory**

```bash
cd ToDo-List
```

**3. Run the application**

Open the `index.html` file directly in your preferred web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

No additional package installation or build configuration is required.

## Application Workflow

1. The user enters a task through the input interface.
2. JavaScript captures the task details and dynamically adds the task to the list.
3. Users can edit tasks to update their descriptions.
4. Completed tasks can be marked accordingly.
5. Unnecessary tasks can be deleted from the list.
6. The interface dynamically reflects changes as users interact with the application.
